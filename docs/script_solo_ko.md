## 정확도에 대해

이 대본은 원본 영상을 장면 단위로 분석한 결과를 바탕으로 만들었습니다. 발화
순서·개수·내용은 원본과 1:1로 맞췄지만, **공식 자막(transcript)을 글자 그대로
받아 옮긴 것은 아닙니다.** 완전히 한 글자도 다르지 않게 맞추려면 유튜브
자막(transcript)을 그대로 넘겨주시면 각 줄에 맞춰 다시 정렬하겠습니다.

오프닝에 흐르는 노래 가사는 옮기지 않았습니다. 그 부분은 직접 만든 곡의
가사로 채우시면 됩니다.

## 이 대본을 영상으로 만드는 방법

1. `python -m scripts.seed_solo_project` — 이 대본이 프로젝트로 들어갑니다.
2. `python -m scripts.make_placeholder_assets demo-solo --with-audio` — 비용 0원으로 전체 흐름 확인
3. `GEMINI_API_KEY` 설정 후 UI에서 "전체 생성" — 이미지와 음성 실제 생성
4. "영상 렌더링" — 한글 자막이 구워진 mp4 + 배포용 .srt 출력
